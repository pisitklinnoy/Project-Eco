# Sample Images Directory

วางไฟล์ภาพทดสอบจากกล้อง CCTV หาดใหญ่ (Train / Test split) ในโฟลเดอร์นี้
ตัวอย่างฟอร์แมตที่รองรับ:
- `.jpg`
- `.jpeg`
- `.png`

ไฟล์ภาพที่วางที่นี่สามารถนำไปใช้ในสคริปต์ `train_detector.py` และสามารถนำไปจำลองส่งเข้า MinIO Bucket `raw-camera-images` เพื่อทดสอบระบบ Vision Pipeline ได้ครับ
